How matching works

A rule is a case-insensitive substring matched against merchant + description. A "=" prefix means exact merchant/description match ("=railway"); spaces are significant ("pub " won't match "public"). Precedence is the order of the list below: the first category with a matching pattern wins, so keep narrow categories above broad ones that would also catch them. One pattern per line.
